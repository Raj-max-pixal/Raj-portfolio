# Rajasaranya Portfolio

Premium personal portfolio website for **Raj Saranya T** — AI Full Stack Developer & Founder of Multimax.

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- GSAP + ScrollTrigger
- Lenis Smooth Scroll
- React Icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
npm run preview
```

## Deploy to GitHub

```bash
git init
git add .
git commit -m "Premium portfolio for Rajasaranya"
git branch -M main
git remote add origin https://github.com/Raj-max-pixal/Raj-portfolio.git
git push -u origin main
```

## Deploy to Vercel

1. Push your code to GitHub
2. Go to [vercel.com](https://vercel.com) and import your repository
3. Vercel auto-detects Vite — click Deploy

Or use the CLI:

```bash
npm i -g vercel
vercel --prod
```

## Resume

Place your resume PDF at `public/resume.pdf` for the download button to work.
